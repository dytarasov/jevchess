# Jev Chess

Веб-шахматы против **TypeSafe Jev** (`typesafe/jev-1.13` на OpenRouter). Jev — не чат-модель, а модель решений: на вход она берёт состояние, на выход отдаёт выбор или оценку с калиброванными вероятностями и не пишет ни слова текста. Здесь она играет в шахматы.

- **Я против Jev**: играете сами, за белых или за чёрных.
- **Stockfish против Jev**: смотрите, как Jev играет против движка нужной силы.

**Все шахматные решения принимает Jev**: какие варианты смотреть, как оценить позицию, какой ход сыграть. Код только применяет правила через python-chess: проверяет легальность, двигает фигуры, фиксирует мат, пат и ничьи. Своих оценок, подсказок или рейтинга ходов Jev не получает.

## Запуск

Нужны Python 3.10+, ключ [OpenRouter](https://openrouter.ai/settings/keys) и, для режима против движка, Stockfish.

```sh
git clone git@github.com:dytarasov/jevchess.git && cd jevchess
echo 'OPENROUTER_API_KEY=sk-or-...' > .env
brew install stockfish        # Linux: apt install stockfish
./run.sh                      # при первом запуске создаст .venv и поставит зависимости
```

Откройте http://localhost:8766.

| переменная | по умолчанию | что задаёт |
|---|---|---|
| `OPENROUTER_API_KEY` | — | ключ OpenRouter (из окружения или `.env`) |
| `PORT` | `8766` | порт сервера |
| `STOCKFISH` | из `PATH` | путь к бинарнику Stockfish |

## Как думает Jev

Три уровня, выбираются в интерфейсе:

**Интуиция.** Один запрос. Jev видит позицию (FEN, доску, списки фигур, запись партии) и одним вопросом `choice` выбирает ход среди всех легальных.

**Обдумывание (MCTS)** (`jevsearch.py`). Дерево в духе AlphaZero: в каждой позиции Jev даёт вероятности ходов и оценку позиции, а дерево растёт туда, куда указывают его ответы.

**Глубокий расчёт** (`jevdeep.py`, по умолчанию). Выборочный минимакс:

1. На корне смотрятся ходы, которые Jev считает вероятными (до 8). Ответы соперника — самые вероятные по мнению Jev плюс все его взятия: это правило перебора «проверь форсированные ходы», а не оценка.
2. Размены досчитываются до конца (quiescence): какое взятие смотреть, решает Jev, плюс ответное взятие на то же поле. Позицию не оценивают посреди размена.
3. Ход оценивается по лучшему ответу соперника (минимакс), а не по среднему, поэтому один опровергающий ответ перевешивает семь безобидных.
4. Оценка позиции — тоже Jev. Материал он считает поштучно («сколько у белых ладей?»), а код только складывает ответы с ценностью фигур 1/3/3/5/9. К этому добавляется его общая оценка перевеса.
5. Финальный ход выбирает Jev. Он видит свои линии и свои оценки в порядке ходов на доске, без рейтинга, и может сыграть любой легальный ход. В 10% позиций он отступает от собственного расчёта.

На ход уходит около 240 позиций (~7 с, ~$0.025). Уровень **«Максимум»** дополнительно усредняет каждую оценку с зеркальной доской: запросов вдвое больше.

Упор в лимит OpenRouter (HTTP 429) обрабатывается так: клиент ждёт столько, сколько просит сервер (`Retry-After` / `X-RateLimit-Reset`), и эта пауза общая для всех потоков. Если лимит так и не отпустил, интерфейс сам повторяет ход.

## Бенчмарк

### Качество ходов на тестовых позициях

`eval/positions.json`: 150 позиций из партий слабых движков с примесью случайных ходов. Для каждой позиции Stockfish (глубина 12) заранее оценил **все** легальные ходы. Stockfish здесь только экзаменатор, Jev его оценок не видит. Метрики:

- **потери** — сколько сантипешек в среднем теряет ход Jev относительно лучшего;
- **зевки** — доля ходов, теряющих 200 сп и больше;
- **лучший ход** — доля ходов в пределах 10 сп от лучшего.

Первые 60 позиций набора:

| версия | потери | зевки | лучший ход | запросов на ход | цена за ход |
|---|---|---|---|---|---|
| случайный ход | 263 сп | 47% | 5% | — | — |
| интуиция | 219 сп | 38% | 27% | 1 | $0.0001 |
| обдумывание (MCTS, 48 позиций) | 186 сп | 32% | 23% | 49 | $0.005 |
| минимакс + досчёт разменов | 117 сп | 17% | 28% | 237 | $0.023 |
| то же + зеркальная доска | 102 сп | 15% | 27% | 473 | $0.035 |
| **минимакс + поштучный материал** (текущий «Глубокий расчёт») | **66 сп** | **10%** | **37%** | 237 | $0.031 |

Что проверили и отбросили:

| идея | результат |
|---|---|
| несколько позиций в одном запросе к Jev | точность оценки падает с 0.70 до 0.45–0.52 |
| вопросы про угрозы («висит ли фигура», «есть ли угроза мата») | к оценке почти ничего не добавляют |
| глубина 3 при том же бюджете (6/6/3) | хуже: 130 сп против 117, поиск слишком узкий |

Главный прирост дали два изменения: оценивать ход по лучшему ответу соперника и перестать спрашивать у Jev материал одним вопросом. На вопрос «у кого больше материала» он ошибался на 3 пешки и больше в 52 из 150 позиций, а поштучный подсчёт верен в 96% ответов.

### Партии против Stockfish

Stockfish уровня 0 (Skill Level 0, 0,05 с на ход), цвета чередуются, очки с точки зрения Jev:

| Jev | партий | +/=/− | очки | средняя длина |
|---|---|---|---|---|
| интуиция | 6 | 0 / 1 / 5 | 0.5 / 6 | 48 полуходов |
| обдумывание (MCTS) | 4 | 0 / 0 / 4 | 0 / 4 | 92 полухода |
| глубокий расчёт | 4 | 0 / 1 / 3 | 0.5 / 4 | 99 полуходов |

Выиграть у Stockfish 0 пока не удалось. Качество отдельных ходов выросло втрое, но за партию из ~50 ходов даже 10% зевков дают движку несколько шансов, и он их использует. Партий мало, это ориентир, а не рейтинг.

Повторить:

```sh
.venv/bin/python eval/build_positions.py --n 150           # набор позиций (нужен только Stockfish)
.venv/bin/python eval/run.py intuition deep --limit 60     # качество ходов
.venv/bin/python bench.py --jev deep --vs sf0 --games 4    # партии; ходы сохраняются в bench_games/
.venv/bin/python eval/blunders.py                          # где в этих партиях Jev ошибался сильнее всего
```

## Файлы

| файл | что делает |
|---|---|
| `server.py` | HTTP-сервер: правила, игроки, API |
| `jevdeep.py` | глубокий расчёт: минимакс с досчётом разменов |
| `jevsearch.py` | обдумывание в стиле MCTS |
| `jev.py` | клиент Jev: эндпоинт `/api/alpha/decisions`, повторы, обработка 429 |
| `index.html` | доска и интерфейс |
| `bench.py` | матчи без браузера и таблица результатов |
| `eval/` | тестовые позиции, замер качества ходов, разбор ошибок |
