# Jev Chess

Веб-шахматы против [TypeSafe Jev](https://openrouter.ai) (`typesafe/jev-1.13`), модели решений: на вход она берёт состояние, на выход отдаёт типизированные ответы с калиброванными вероятностями. Играть можно самому против Jev или смотреть, как против Jev играет Stockfish.

**Все шахматные решения принимает Jev**: какие варианты смотреть, как оценить позицию и какой ход сыграть. Код только применяет правила (python-chess): двигает фигуры, проверяет легальность и фиксирует мат, пат и ничьи. Своих оценок, подсказок и рейтинга ходов код Jev не даёт.

## Запуск

```sh
echo 'OPENROUTER_API_KEY=sk-or-...' > .env
brew install stockfish      # нужен только для режима «Stockfish против Jev»
./run.sh                    # → http://localhost:8766
```

## Уровни Jev

**Интуиция.** Один запрос. Jev видит позицию (FEN, доску, список фигур, запись партии) и выбирает ход одним `choice` среди всех легальных ходов.

**Обдумывание** (`jevsearch.py`). Поиск по дереву, похожий на AlphaZero, только вместо нейросети работает Jev:

1. В каждой исследуемой позиции Jev одним запросом отвечает на три вопроса:
   - `policy`: какой ход он бы сыграл (`choice`);
   - `advantage`: у кого перевес (`score`, 7 уровней);
   - `material`: у кого больше материала (`score`, 9 уровней).
2. Дерево растёт по схеме PUCT. Какие ходы раскрывать, определяют вероятности Jev; куда смотреть глубже, определяют его оценки позиций. Позиции раскрываются волнами по 8 штук, запросы внутри волны идут параллельно.
3. Финальный ход тоже выбирает Jev. Ему показывают позицию и его собственные заметки: просмотренные линии и его оценку в конце каждой. Линии идут в порядке ходов на доске, без рейтинга и без «лучшего варианта». Сыграть он может любой легальный ход.

48 позиций занимают около 5 с и стоят примерно $0.005 за ход.

## Файлы

| файл | что делает |
|---|---|
| `server.py` | HTTP-сервер: правила, игроки, API |
| `jevsearch.py` | обдумывание хода деревом вариантов |
| `jev.py` | клиент Jev (эндпоинт OpenRouter `/api/alpha/decisions`) |
| `index.html` | доска и интерфейс |
