# Jev Chess

Веб-шахматы против **TypeSafe Jev** (`typesafe/jev-1.13` на OpenRouter). Jev — не чат-модель, а модель решений: на вход она берёт состояние, на выход отдаёт выбор или оценку с калиброванными вероятностями и не пишет ни слова текста. Здесь она играет в шахматы.

- **Я против Jev**: играете сами, за белых или за чёрных.
- **Stockfish против Jev**: смотрите, как Jev играет против движка нужной силы.

**Все шахматные решения принимает Jev**: какие варианты смотреть, как оценить позицию, какой ход сыграть. Код только применяет правила через python-chess: проверяет легальность, двигает фигуры, фиксирует мат, пат и ничьи. Своих оценок, подсказок или рейтинга ходов Jev не получает.

## Запуск

Нужны Python 3.10+, ключ [OpenRouter](https://openrouter.ai/settings/keys) и, для режима против движка, Stockfish.

```sh
git clone git@github.com:dytarasov/jevchess.git && cd jevchess
echo 'OPENROUTER_API_KEY=sk-or-...' > .env
brew install stockfish        # Linux: apt install stockfish
./run.sh                      # при первом запуске создаст .venv и поставит зависимости
```

Откройте http://localhost:8766.

| переменная | по умолчанию | что задаёт |
|---|---|---|
| `OPENROUTER_API_KEY` | — | ключ OpenRouter (из окружения или `.env`) |
| `PORT` | `8766` | порт сервера |
| `STOCKFISH` | из `PATH` | путь к бинарнику Stockfish |

## Как думает Jev

**Интуиция.** Один запрос. Jev видит позицию (FEN, доску, списки фигур, запись партии) и одним вопросом `choice` выбирает ход среди всех легальных.

**Обдумывание** (`jevsearch.py`). Поиск по дереву, похожий на AlphaZero, только вместо нейросети работает Jev:

1. В каждой исследуемой позиции Jev одним запросом отвечает на три вопроса: какой ход он бы сыграл (`choice`), у кого перевес (`score`) и у кого больше материала (`score`).
2. Какие ходы раскрывать, определяют вероятности Jev, куда смотреть глубже — его оценки позиций (схема PUCT). Позиции раскрываются волнами по 8, запросы внутри волны идут параллельно.
3. Финальный ход тоже выбирает Jev. Ему показывают позицию и его собственные заметки: просмотренные линии и его оценку в конце каждой. Линии идут в порядке ходов на доске, без рейтинга и без «лучшего варианта». Сыграть он может любой легальный ход.

Упор в лимит OpenRouter (HTTP 429) обрабатывается так: клиент ждёт столько, сколько просит сервер (`Retry-After` / `X-RateLimit-Reset`), и эта пауза общая для всех потоков. Если лимит так и не отпустил, интерфейс сам повторяет ход.

## Бенчмарк

Jev против Stockfish уровня 0 (Skill Level 0, 0,05 с на ход): самый слабый уровень движка, но для человека это всё ещё уверенная любительская игра. Цвета чередуются, очки считаются с точки зрения Jev. Замер от 23.09.2026.

| Jev | соперник | партий | +/=/− | очки | средняя длина партии | время на ход | цена за ход |
|---|---|---|---|---|---|---|---|
| интуиция | Stockfish 0 | 6 | 0 / 1 / 5 | 0.5 / 6 | 48 полуходов | 0.5 с | $0.0001 |
| обдумывание, 48 позиций | Stockfish 0 | 4 | 0 / 0 / 4 | 0 / 4 | 92 полухода | ~10 с* | $0.0044 |
| обдумывание, 48 позиций | интуиция | 2 | 1 / 1 / 0 | 1.5 / 2 | — | — | — |

\* Около 5 с чистого обдумывания, остальное — ожидание после 429: шесть параллельных партий упирались в общий лимит OpenRouter на Jev (10–16 раз за партию). Ни один ход при этом не сорвался.

Итог: обдумывание выиграло очную встречу у интуиции 1.5 : 0.5 и держится против движка почти вдвое дольше, но выиграть у Stockfish даже на уровне 0 пока не может. Выборка маленькая, это ориентир, а не рейтинг.

Повторить:

```sh
.venv/bin/python bench.py --jev intuition --vs sf0 --games 6
.venv/bin/python bench.py --jev think --budget 48 --vs sf0 --games 4
.venv/bin/python bench.py --jev think --vs intuition --games 2
```
